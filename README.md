# Axiom

Axiom is now split into three parts:

- `axiom_core/`: shared bounded symbolic adaptive-intelligence engine.
- `competition/`: offline ARC-AGI-3 Kaggle notebook package using the official `MyAgent(Agent)` interface.
- `startup/`: local Axiom Runtime adaptive-environment research platform.

Run `make test`, `make competition-notebook`, `make competition-validate`, and `make competition-smoke`.
