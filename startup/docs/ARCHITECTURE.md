# ARCHITECTURE

Axiom Runtime is adaptive intelligence infrastructure for unfamiliar interactive environments. It uses the shared `axiom_core` engine to observe state, infer executable causal hypotheses, estimate risk and reversibility, and choose legal actions under runtime deadlines.

## Current status

This is an alpha research platform. It has local grid, workflow, and browser-sandbox demos, replayable sessions, safety approval hooks, and a React/Vite studio scaffold. It does not claim customers, revenue, partnerships, general intelligence, or production reliability.

## Milestones

1. Run and validate official ARC-AGI-3 public games without crashes.
2. Improve causal rule induction and goal posterior on public/procedural splits.
3. Harden browser sandbox safety, redaction, approvals, and audit logs.
4. Produce a 60-second demo showing live world-model updates on a randomized app.

## Limitations

The symbolic engine is bounded and conservative. Complex software workflows, rich visual interfaces, and hidden objectives can still fail without better perception, planning, and verified rule composition.
