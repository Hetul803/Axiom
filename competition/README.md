# Competition package

`competition` contains an offline, self-contained ARC-AGI-3 notebook generator. Keep Kaggle's generic first setup cell unchanged, then copy cells 01 through 06 from `notebook_cells.md` in order.

The local `competition/agent/my_agent.py` uses the official starter interface: `MyAgent(Agent)`, `is_done(frames, latest_frame)`, and `choose_action(frames, latest_frame)`.
