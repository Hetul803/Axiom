# Axiom Scientist V3

V3 combines exact connected-component/grid evidence with alternate ontology particles, generated executable world models, AST and subprocess validation, full-history replay verification, smallest-cell counterexamples, posterior normalization, and disagreement-driven experiments. Generated programs never directly issue real actions. The controller validates legal actions, executes verified plans one step at a time, clears a plan on mismatch, and falls back to copied V2 systematic exploration.

Scientist and Critic requests use separate bounded evidence streams and versioned structured prompts. Scientist output is accepted only after static validation and replay. Critic output is advisory; the deterministic controller retains action authority. The local client is capped at 12 calls and 32,768 generated tokens per game, with request and global deadlines.
